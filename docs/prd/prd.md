## 2. 项目概述

### 2.1 定位

通用型本地 AI 音频工作台，覆盖三大能力：剧本生成（LLM）、人声合成（TTS）、背景音乐生成、最终混音合成。面向**本地单机单用户**，不做多用户、不做云端部署。

### 2.2 核心约束

- TTS 引擎仅对接：阿里云（Qwen-TTS / CosyVoice）与火山引擎（豆包 TTS），不支持声音克隆。
- 播客仅支持单人讲述（二期交付）。
- 模块解耦：剧本、TTS、背景音、混音四者可独立使用，也可组合成成品。
- 所有数据（剧本、音频产物）存储于本机，不上传云端对象存储。

### 2.3 与原型 PRD V2.2 的差异（正式版结论）

| 原型 PRD 条目 | 正式版处理 |
|---|---|
| 存储 OSS | 改为本地文件存储（单机用户，无上云必要） |
| 敏感词过滤 | 砍掉（LLM / TTS 服务商自带内容安全） |
| 用量统计面板 / 月度预算告警 | 砍掉 |
| 并发 5 任务不排队 | 改为全局单任务串行队列（单机单人） |
| 闪避双模式 | 仅保留模式 B「人声时压低」（行业常规）；模式 A「静音段压低」删除 |
| 「纯音乐」独立场景 | 不单设场景：BGM 模块独立使用 + 混音页仅选背景轨 |
| MVP 优先级 P1 播客 | 播客移至二期；一期 = 冥想 + TTS + BGM + 混音 |
| 架构图背景音误入 TTS | 按原型修正：背景音轨直达混音，不经 TTS |

## 3. 用户与核心场景

| 场景 | 路径 | 说明 |
|---|---|---|
| 冥想成品 | 冥想工作台生成剧本 →（编辑）→ TTS 人声 →（可选 BGM）→ 混音导出 | 主路径 |
| 纯音乐 | BGM 模块直接生成 → 混音页仅选背景轨导出 | 背景音模块独立使用 |
| 播客成品（二期） | 播客工作台生成/润色剧本 → TTS → 混音 | 二期交付 |
| 自由组合 | 各模块产物均入库，任意下游模块从产物库选择输入 | 模块解耦原则 |

## 4. 整体流程

```text
┌──────────────────────────────────────────────────┐
│ 冥想工作台（一期）/ 播客工作台（二期）             │
│ 输入：主题/话题 + 目标时长(5/10/15/20/25/30min) + 模型 │
│   输出：带标记脚本文本（产物）                      │
└───────────────┬──────────────────────────────────┘
                │ 产物库选择 / 页面直接流转
┌───────────────▼──────────────────────────────────┐
│ TTS 人声合成                                      │
│   输入：脚本产物或粘贴文本 + 引擎/音色/语速/场景    │
│   输出：人声干声音频（产物，WAV/MP3）              │
└───────────────┬──────────────────────────────────┘
                │                    ┌──────────────┐
                │                    │ BGM 背景音乐  │
                │                    │ 风格+时长+结构 │
                │                    │ → 音轨（产物） │
                │                    └──────┬───────┘
┌───────────────▼──────────────────────────────▼───┐
│ 最终混音                                          │
│   人声轨（可选）+ 背景轨（可选，至少其一）          │
│   音量比例 / 偏移 / 闪避(模式B) → MP3/WAV 成品     │
└──────────────────────────────────────────────────┘
```

关键原则：

1. 剧本生成先进入会话工作草稿，用户手动保存后形成带版本的脚本产物；TTS、BGM 等耗时/计费结果自动入库。
2. 混音是组合层，不关心人声来源，只做音轨叠加。
3. 跨模块流转 = 产物库 + 页面跳转预选（原型 handoff 机制的 SPA 化）。

## 5. 功能需求

### 5.1 模块一：冥想剧本工作台（一期，P0）

**交互形态**：对话式工作台（多轮消息流），同 article-studio 文章线范式。

**输入与参数**：

- 主题关键词（如"深海放松"），空主题禁用发送。
- 目标时长：5 / 15 / 30 分钟三档（气泡设置控件，同原型）。
- LLM 模型切换（DeepSeek / 通义千问，运行中锁定）。

**生成行为**：

- 用户发送主题 → 流式生成结构化脚本（逐字增量呈现于消息气泡）。
- 脚本必须包含标记：`[停顿 Ns]`（静默）、`[情绪:温柔]`（语气）、`[吸气]` / `[呼气]`（呼吸指引）、`[语速:慢速]`（节奏）。
- 脚本结构：引导进入 → 主体（呼吸/身体扫描/意象）→ 收尾唤醒；篇幅与目标时长匹配。
- 支持多轮 refinement：用户可继续说"再温柔一些""缩短到 5 分钟"，LLM 基于会话历史修改。
- 支持失败重试、运行中取消（丢弃临时内容）。

**结果展示**：

- 标记徽章渲染（彩色徽章，非纯文本）。
- 时间轴条：语音段/停顿段分段着色 + 预估总时长（由脚本解析而来）。

**编辑闭环**：

- 结果可在工作台内切换编辑模式（textarea）；人工编辑短延迟自动保存为工作草稿并重新解析时间轴与预估时长，不覆盖正式版本。
- 每个会话至多对应一个逻辑剧本产物：首次手动保存要求命名并创建 v1，后续手动保存追加不可变版本；AI 生成只更新可恢复草稿。
- 版本历史支持查看与恢复为草稿；恢复后再次保存产生新版本，不重写历史。

**流转**：「送去 TTS」→ 跳转 TTS 页并自动预选该产物。

### 5.2 模块二：TTS 人声合成（一期，P0）

**输入**：

- 脚本来源：产物库脚本下拉（冥想 + 二期播客）+ 粘贴文本兜底。
- 场景类型（冥想引导 / 单人播客）：切换联动参数预设——冥想默认语速 0.8x + 推荐音色高亮 + 预设说明；来源为脚本产物时自动判定。
- 引擎选择（阿里云 / 火山引擎）→ 联动音色下拉（官方音色库）。
- 音色选择 + **试听**（短句真实合成，结果按「引擎+音色」缓存，重复试听不重复计费）。
- 语速 0.5x–1.5x；音调（可选）。

**标记处理**（对用户透明的后端行为，PRD 层面承诺结果）：

- `[停顿 Ns]` → 优先走引擎 SSML break（引擎内自然停顿），超长或不支持时切分为独立静音段；`[吸气]` → 4s 静音、`[呼气]` → 5s 静音（符合真实冥想呼吸节奏）；`[情绪:x]` → 阿里云 Qwen-TTS 经 instruction 自然语言情感指令直传（已验证），火山引擎按能力声明降级为普通朗读（风格由音色预设覆盖）；`[语速:x]` → 分段语速；标记一律不朗读出口。

**合成与展示**：

- 分段合成进度（第 n/N 段）实时呈现；耗时任务走统一运行态（排队/运行/完成/失败/取消）。
- 结果：音频播放器 + 波形可视化 + 时长/格式信息；自动入库（含完整参数快照与来源脚本）。
- 失败给出结构化错误（引擎错误/额度不足/文本超限），可重新提交。

**流转**：「送去混音」→ 混音页自动预选人声轨。

**性能目标（软性）**：15 分钟音频从提交到可预览 ≤ 3 分钟。

### 5.3 模块三：BGM 背景音乐（一期，P1）

**输入**：

- 自由 Prompt：直接描述风格、情绪、场景、乐器和演奏方式，支持跨风格融合；可选灵感示例只负责填充/追加文本，不形成正式风格枚举。
- 目标时长：1–10 分钟（滑块）。
- 结构倾向（可选多选）：Intro / Build Up / Drop / Outro；作为非确定性 Prompt 提示，不承诺模型精确分段。
- 输出格式：MP3 / WAV。

**生成与展示**：

- MiniMax Music 同步接口生成（典型 1–3 分钟单次调用返回结果）：提交 → 排队/等待进度（已等待时长心跳）→ 完成立即下载持久化入库（不依赖服务商临时 URL 的有效期，记录 URL 过期时间）。
- 结果：播放器 + 波形（按段落结构呈现能量差异）+ 参数摘要；失败/取消给出明确反馈。
- 生成失败**不自动重试**（防止重复计费）：若失败前已拿到音频 URL，重试按钮提供「重新下载」（免计费，URL 有效期内）；仅当无结果或 URL 已过期时提供「重新生成」（界面二次确认）。
- 取消 = 停止等待并放弃结果（服务商侧任务与计费可能已发生，界面向用户说明）。
- 背景音轨统一后处理：按目标时长循环填充/截断 + 首尾淡入淡出 + 最终时长复验。

**流转**：「送去混音」→ 混音页自动预选背景轨。纯音乐场景 = 本模块独立使用 + 混音页仅选背景轨。

### 5.4 模块四：最终混音（一期，P0）

**输入**：

- 人声轨：产物库 voice 下拉，**可为空**（纯音乐导出）。
- 背景音轨：产物库 bgm 下拉，可为空；两者至少其一。
- 人声/背景相对音量（各 0–100）。
- 背景音起始偏移（0–60s 滑块）。
- 闪避：开关（仅模式 B「人声出现时压低背景音，静默时恢复」；模式 A 已删除）。
- 导出格式：MP3（320kbps）/ WAV（16bit / 48kHz）。全链路音频基准采样率 48kHz（两家 TTS 引擎原生输出档位，避免多余重采样）。

**规则**（界面明确提示）：

- 背景音短于人声 → 循环填充至等长；长于人声 → 截断。
- 仅人声 → 透传（按所选格式重编码）；仅背景音 → 原样导出。
- 单轨或无闪避组合时闪避自动失效。

**展示**：

- 双轨波形预览（人声/背景上下叠放，偏移可视化）。
- 合成进度（准备→闪避分析→编码）；结果：播放器 + 混音波形 + 自动入库。

### 5.5 产物库（一期，P0）

- 类型筛选 Tab：全部 / 冥想脚本 /（二期：播客脚本）/ 人声 / 背景音 / 成品。
- 卡片信息：名称、类型徽章、参数摘要（时长/引擎/音色/风格/格式等）、生成时间。
- 操作：查看详情（完整参数与内容/音频）、重命名、删除（确认）、脚本版本查看/恢复、**送下游**（脚本→TTS、人声/背景→混音，跳转并预选）、清空全部（确认）。
- 音频产物支持在线播放与（浏览器）下载保存。

### 5.6 首页（一期，P0）

- 模块卡片入口（冥想/TTS/BGM/混音/产物库）。
- 产物计数、最近 5 条产物。
- 快速开始引导：生成剧本 → TTS 人声 →（可选）背景音 → 混音导出。
- 全局运行态提示（队列中/进行中的任务）。

### 5.7 设置（一期，P0）

- 浏览器可编辑 DeepSeek、通义千问、Kimi、阿里云 TTS、火山 TTS、MiniMax 的凭据及对应模型参数，保存后无需重启，对后续开始执行的任务立即生效。MiniMax 模型 ID 默认为 `music-3.0`。
- LLM/MiniMax 超时参数可编辑；FFmpeg、FAKE_MODE 等本地环境配置只读。
- 页面默认以密文展示凭据；仅 `DATA_DIR/settings.json` 中由浏览器保存的值可点击查看和修改，`.env` 凭据禁止回显。火山 App ID 可直接查看，Access Token 默认隐藏并单独点击显示。
- 每项「测试连通」按钮：真实轻量探测（如合成一句短音频/列模型），返回成功/失败与原因。
- 引擎版本等环境信息展示。

## 6. 通用交互规范（继承原型）

1. **运行态规范**：任何生成任务提交后进入运行态——输入锁定、进度可见、可取消；排队中显示队列状态。
2. **错误规范**：结构化错误码 + 人性化文案 + 可重试；失败不落库脏数据。
3. **空态规范**：产物库为空时下游页给出空态引导（去生成/去上游）。
4. **保存语义**：TTS/BGM/混音完成后自动保存产物（耗时/计费产物不可丢）；剧本草稿自动恢复，正式版本仅由用户手动追加。
5. **参数快照**：所有产物保存完整生成参数，可回溯。
6. 暗色专业工具风视觉（沿用原型风格 tokens）。

## 7. 非功能需求

| 指标 | 要求 |
|---|---|
| 部署形态 | 本地单机：FastAPI 单进程同时服务 API 与前端静态资源 |
| 任务并发 | 全局单任务串行队列（FIFO），队列上限 8，超出拒绝并提示 |
| TTS 性能 | 15 分钟音频提交到预览 ≤ 3 分钟（软目标） |
| BGM 性能 | 受 MiniMax 服务侧制约（典型 1–3 分钟），进度透明可取消 |
| 数据安全 | 全部数据落本机 `DATA_DIR`；API Key 仅存 `.env` 或本机 `DATA_DIR/settings.json`，不入 SQLite、不写日志；仅浏览器保存值可经禁止缓存的专用接口按字段回显，`.env` 永不回显；配置读写仅面向绑定 `127.0.0.1` 的本机可信用户，不提供登录鉴权 |
| 可靠性 | 产物自动入库；服务重启后已完成产物不丢失、运行中任务标记失败可重提 |

## 8. 分期规划

### 一期（本期）

| 优先级 | 模块 |
|---|---|
| P0 | 冥想剧本工作台、TTS 合成、最终混音、产物库、首页、设置 |
| P1 | BGM 背景音乐 |

### 二期（规划，不在本期范围）

- 播客剧本工作台：对话式交互同冥想；输入双模式（话题关键词生成 / 长文本润色改编，意图自动识别：文本 ≥50 字或含"润色/改编/改写/整理"关键词且 ≥20 字 → 润色模式）；时长档位与冥想一致；其余复用一期 TTS/混音链路。
- 明确不做：声音克隆、多人播客、云端部署、多用户。
