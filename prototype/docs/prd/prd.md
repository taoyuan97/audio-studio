1. 项目概述
1.1 背景与目标
产品定位：通用型AI音频工作台，覆盖冥想引导、单人播客、纯音乐三大场景。

核心约束：TTS引擎仅对接阿里云（Qwen-Audio-3.0-TTS）和火山引擎（豆包TTS）；暂不支持声音克隆；播客仅支持单人讲述。

1.2 架构原则
模块独立：剧本生成、TTS合成、背景音生成、最终合成四者解耦。

灵活组合：用户可单独生成剧本、单独合成人声、单独生成背景音，或组合导出成品。

3. 功能模块详细设计
3.1 模块一：剧本生成——冥想场景（独立功能）
输入：

主题关键词（如“深海放松”“焦虑缓解”“清晨唤醒”）

目标时长（5 / 15 / 30 分钟）

处理流程：

调用国产大模型（DeepSeek / 通义千问），注入冥想专用Prompt模板

生成结构化引导脚本，必须包含以下标记：

[停顿 5s] — 静默间隙

[情绪:温柔] — 语气标签（供TTS识别）

[吸气] / [呼气] — 呼吸指引

[语速:慢速] — 节奏控制

输出：带时间轴标记的纯文本脚本

输出示例：

text
欢迎来到今天的放松练习 [情绪:温柔]
[停顿 3s]
请找一个舒适的位置坐下 [语速:慢速]
[吸气] 感受空气进入身体 [停顿 2s]
[呼气] 释放所有的紧张 [情绪:舒缓]
3.2 模块二：剧本生成——播客场景（独立功能）
输入方式（二选一）：

方式A：用户输入话题关键词（如“AI时代的学习方法”）

方式B：用户上传已有文本（如公众号文章、笔记），AI进行润色改编

处理流程：

调用国产大模型（DeepSeek / 通义千问），注入播客专用Prompt模板

生成单人讲述脚本，结构包含：开场引入 → 主体内容 → 总结收尾

输出：自然流畅的讲述脚本（无需特殊标记，纯文本即可）

输出示例：

text
大家好，欢迎收听今天的节目。
今天我们来聊聊AI时代的学习方法。
过去我们习惯线性学习，但AI给了我们新的可能性...
（正文内容）
感谢收听，我们下期再见。
3.3 模块三：TTS合成（统一人声合成引擎）
定位：独立模块，接收任意场景的脚本，输出纯人声干声。

输入：

脚本文本（来自冥想模块或播客模块）

场景类型标识（冥想引导 / 单人播客 / 纯音乐）—— 影响TTS参数预设

引擎选择：阿里云 / 火山引擎

音色选择（各平台预设音色库）

语速调节（0.5x ~ 1.5x）

音调调节（可选）

三类场景的TTS参数预设：

场景	推荐语速	推荐音色风格	特殊参数
冥想引导	0.8x（偏慢）	温柔女声 / 空灵男声	需识别 [情绪:温柔] 等标签
单人播客	1.0x（正常）	知性女声 / 沉稳男声	自然流畅，无需特殊情绪标签
纯音乐	无（纯音乐不含人声）	不适用	此场景不调用TTS
输出：

纯人声干声文件（WAV / MP3）

可单独下载保存

3.4 模块四：背景音/纯音乐生成（独立模块）
输入：

风格描述（如“古风禅意”“电子疗愈”“钢琴抒情”）

目标时长（1 ~ 10 分钟）

可选：段落结构标签（[Intro]、[Build Up]、[Drop]、[Outro]）

处理流程：

调用 MiniMax Music 2.5+ API 生成纯音乐

支持跨风格融合指令（如“笛子+电子氛围”）

输出：纯音乐背景音轨（WAV / MP3），可单独下载保存

备选方案：若MiniMax不可用，从版权音效素材库匹配关键词返回已有音轨。

3.5 模块五：最终合成（组合层）
输入：

人声轨（来自TTS模块，冥想或播客场景）

背景音轨（来自背景音模块，纯音乐场景），可选，用户可跳过

调节选项：

人声/背景音 相对音量比例

背景音起始位置偏移

处理逻辑：

背景音循环填充至与人声等长（若短于），或截断（若长于）

闪避效果：检测人声轨中的静音段（≥1秒），在静音段自动降低背景音音量

若无背景音选择，直接输出人声原始文件

输出：

合成成品音频，MP3（320kbps）或 WAV（16bit / 44.1kHz）

4. 模块调用关系总览
步骤	模块	输入	输出	独立性
1a	剧本生成（冥想）	主题+时长	标记脚本	独立，可单独使用
1b	剧本生成（播客）	话题/文本	讲述脚本	独立，可单独使用
2	TTS合成	任意脚本	人声干声	独立，接收两类脚本
3	背景音生成	风格+时长	背景音轨	独立，可单独使用
4	最终合成	人声轨+背景音轨	成品音频	组合层
关键设计原则：

模块1a、1b、2、3均可独立运行并输出中间产物

模块4负责组合，不关心人声来源（冥想还是播客），只做音轨叠加

5. 技术选型汇总
模块	能力需求	推荐技术方案
剧本生成（冥想）	结构化脚本 + 时间轴标记	DeepSeek / 通义千问 + 冥想Prompt模板
剧本生成（播客）	自然讲述脚本	DeepSeek / 通义千问 + 播客Prompt模板
人声TTS合成	情绪标签 / 语速控制	阿里云Qwen-TTS / 火山引擎豆包TTS
背景音生成	风格化纯音乐	MiniMax Music 2.5+ API
音轨合成	对齐 + 闪避 + 导出	FFmpeg（Python SDK封装）
存储	中间产物+成品管理	OSS（阿里云/火山引擎）
6. 非功能需求
指标	要求
端到端延迟	15分钟音频，从提交到预览 ≤ 3分钟
并发支持	同时处理至少5个任务不排队
内容审核	剧本生成环节内置敏感词过滤
成本控制	后台用量统计面板，月度预算告警
商用版权	确认各API服务条款允许商用
7. MVP开发优先级
优先级	模块	说明
P0	剧本生成（冥想）	核心场景，验证大模型生成结构化脚本能力
P0	TTS合成	核心引擎，验证阿里云/火山引擎情绪标签识别
P0	最终合成	人声+背景音叠加，基础闪避效果
