# 播客剧本生成 · 输入区对话化（Agent 形态）改造任务文档

版本：V1.0
创建日期：2026-08-25
依据文档：`prototype/docs/prd/prd.md`（PRD V2.2）、`prototype/docs/task/tasks.md`（初始任务文档 V1.0）、`prototype/docs/task/meditation-chat.md`（冥想页同构改造，已完成）
关联页面：`prototype/podcast-script.html`

---

## 1. 背景与目标

播客剧本生成页现为「Tab 双模式表单」（方式 A 话题关键词 / 方式 B 粘贴文本润色 + 生成按钮）。
本次改造与冥想页同构：输入区升级为**主流 Agent 对话框形态**，自然语言对话交互，工具栏只保留分钟参数设置、大模型切换，加输入框与发送按钮。

**生成结果区域（右栏）保持不变**：进度动画、参数摘要、脚本预览/编辑、存入产物库、送 TTS 全部沿用现状。

## 2. 已确认决策记录

| # | 决策点 | 结论 |
|---|--------|------|
| C1 | 双模式承载方式 | **自然语言自动识别，不加模式控件**：用户在对话框中发话题或粘贴文本，由大模型（mock 启发式）自动判断意图并选择生成方式。工具栏不出现「话题/润色」切换 |
| C2 | 分钟参数作用 | **mock 响应时长**：5 分钟输出基础脚本；15 分钟为每个论点追加展开句；30 分钟再追加延伸段落。档位 5/15/30，与冥想页一致 |
| C3 | 分钟控件来源 | **控件为唯一来源**：只认工具栏 segmented，不从自然语言解析时长（沿用冥想页决策） |
| C4 | 结果区边界 | param chips 补「目标时长」chip（与冥想页对齐，一行模板改动），其余结构/逻辑严格不动。**⚠ 用户未明确确认，默认按推荐处理，实施前可再确认** |
| C5 | 模型切换语义 | 仅前端示意：影响气泡模型徽标与产物 `params.model` 记录，不模拟不同模型间的生成差异（沿用冥想页决策） |
| C6 | 意图识别规则（mock 启发式） | 满足其一判定为文本润色：① 去空白后长度 ≥ 50 字；② 含「润色/改编/改写/整理」关键词且长度 ≥ 20 字。否则为话题生成。判定为润色但 < 20 字时回退话题模式 |
| C7 | 主题提取 | mock 新增 `extractTopic`：优先提取「关于…」「聊聊/谈谈…」后的片段，否则截取前 12 字；用于气泡摘要与产物命名。`params` 另存原始完整输入 `input` |

## 3. 交互方案

### 3.1 布局（与冥想页同构，复用 chat 组件样式）

```
┌─────────────────────────┬─────────────────────────┐
│ 对话卡（左栏，改造）      │ 生成结果卡（右栏，不动）  │
│ ┌─────────────────────┐ │                         │
│ │ 消息流（内部滚动）    │ │  进度动画（双模式步骤） │
│ │  空态：欢迎语        │ │  / 空态 /              │
│ │       + 建议提示词   │ │  param chips           │
│ │  user 气泡（右对齐） │ │  + 润色说明 note       │
│ │  assistant 气泡     │ │  + 脚本预览/编辑 +     │
│ │   · 生成中：当前步骤 │ │  入库 / 送 TTS         │
│ │   · 完成：模型徽标   │ │  （与现状一致，         │
│ │     + 摘要 + 引导语  │ │   仅 C4 增加一个 chip） │
│ ├─────────────────────┤ │                         │
│ │ composer（底部固定） │ │                         │
│ │  工具栏：分钟 segmented│ │                        │
│ │         + 模型下拉   │ │                         │
│ │  输入框 + 发送按钮    │ │                         │
│ └─────────────────────┘ │                         │
└─────────────────────────┴─────────────────────────┘
```

### 3.2 对话流细节

- **空态**：欢迎语（说明两种能力：给话题生成单人讲述脚本 / 粘贴文本润色改编为口播稿）+ 建议提示词列表：
  - 话题类：「帮我写一期关于 AI 时代学习方法的单人播客」「聊聊城市漫步的意义」「做一期关于早起习惯的分享」
  - 润色类：1 条长文本粘贴示例（≥50 字，点击填入演示文本润色路径）
  - 点击建议词 → 填入输入框（不直接发送）
- **user 气泡**：右对齐，显示用户原文（长文本粘贴同样展示）
- **assistant 气泡**（带模型徽标）：
  - 生成中：typing 动画 + 当前步骤（按自动识别的模式取 `GEN_STEPS.topic` 或 `GEN_STEPS.text`）
  - 完成摘要（按模式）：
    - 话题模式：「已围绕「短主题」生成 X 分钟单人讲述脚本 —— 正文 N 字，预计口播约 Y 分钟。可在右侧查看与编辑，或直接送去 TTS 合成。」
    - 润色模式：「已将你的文本（N 字）润色改编为口播脚本 —— 保留核心要点并补充开场收尾。可在右侧查看与编辑，或直接送去 TTS 合成。」
  - 不重复渲染脚本文本（右栏是唯一结果区）
- **历史消息**：可滚动回看；每次发送触发新一次生成并重置右栏结果

### 3.3 composer 结构

- 工具栏：分钟 segmented（5/15/30，紧凑变体）+ 模型下拉（`LLM_MODELS`，默认 DeepSeek）。**无模式切换控件（C1）**
- 输入框：textarea 自适应高度（1~4 行），placeholder 示例「描述你的话题，或直接粘贴一段文本让我润色改编」
- 发送按钮：Enter 发送 / Shift+Enter 换行；空输入禁用；生成中禁用

### 3.4 Mock 逻辑改动（`generatePodcast` 增强，均为确定性变换）

- **意图识别** `classifyPodcastIntent(text)` → `'topic' | 'text'`（规则见 C6）
- **主题提取** `extractTopic(input)` → 短主题（规则见 C7）；话题模式下替换进模板，避免长句撑坏正文
- **时长响应** `generatePodcast({ mode, topic, text, duration })`：
  - 5 分钟：现行基础模板
  - 15 分钟：三个论点各追加一句预置展开句
  - 30 分钟：在 15 分钟基础上再追加「延伸思考」段落（预置文案）
  - 润色模式同步响应：15/30 档在要点梳理后追加展开/延伸段
- 进度动画复用 `GEN_STEPS`（双模式）+ `fakeTask`

### 3.5 状态设计（podcast.js）

| 字段 | 变化 |
|------|------|
| `mode` / `topic` / `pastedText` | **移除**（意图与内容由每次发送解析，存于 `messages[i].meta`） |
| `messages` | **新增**：`[{ role, text, pending?, meta?: { model, modelName, mode, topic?, sourceLength?, duration, wordCount } }]` |
| `model` / `input` / `duration` | **新增**：模型 id / 输入框受控文本 / 时长档位（默认 5） |
| `generating` / `stepDone` / `progress` / `result` / `editing` / `draft` / `savedId` / `dirty` | 保留，语义不变 |

### 3.6 产物入库

- `params` 新增 `model` / `modelName` / `duration` / `input`（原始输入全文）；话题模式 `topic` 存提取后的短主题，润色模式保留 `sourceLength`
- 产物命名：话题模式 `播客脚本 · ${短主题}`；润色模式 `播客脚本 · 文本润色`（现状逻辑，仅话题来源改为短主题）

## 5. 任务分解

### PC1 Mock 层（mock.js）

**内容**
- `classifyPodcastIntent`（C6 规则）、`extractTopic`（C7 规则）+ 导出
- `generatePodcast` 增加 `duration` 参数与档位扩充文案（话题/润色两模式均响应）

**验收标准**
- 控制台可访问两个新函数；`generatePodcast({ mode:'topic', topic:'…', duration:15 })` 正文字数大于 `duration:5`

### PC2 页面重构（podcast.js + podcast-script.html）

**内容**
- state 改造（见 3.5）
- 左栏对话渲染：空态（欢迎语 + 建议词含长文本示例）、消息流、composer（无模式控件）
- 发送交互：Enter/按钮发送、空输入禁发、生成中禁发、建议词点击填入
- 发送时调用 `classifyPodcastIntent` 自动选择生成链路与进度步骤；完成后填充模式对应的摘要气泡
- `doSave` params 扩展（3.6）；结果区补「目标时长」chip；page-desc 文案更新

**验收标准**
- 见第 6 节总验收清单

### PC3 联调验收

**内容**
- 本页全流程走查（双模式 × 双时长档 × 双模型）+ 冥想页回归（mock 改动零影响）+ TTS handoff / 产物库确认

## 6. 验收标准（总清单）

- [ ] 空态显示欢迎语 + 建议提示词（含 1 条长文本润色示例），点击填入输入框
- [ ] 短句话题（如「聊聊城市漫步的意义」）→ 自动走话题模式：进度步骤为 topic 组，气泡摘要含提取的短主题，正文主题词为短主题而非整句
- [ ] 粘贴长文本（≥50 字）或含「润色/改编」关键词的 ≥20 字输入 → 自动走润色模式：进度步骤为 text 组，结果区显示润色说明 note，正文含原文要点
- [ ] 分钟切换 15/30 后发送 → 正文字数明显增加（论点展开/延伸段），结果区「目标时长」chip 正确
- [ ] 模型切换 → 下次生成气泡徽标与产物 params 记录正确
- [ ] Enter 发送 / Shift+Enter 换行；空输入禁发；生成中发送按钮禁用
- [ ] 生成中：右栏进度动画正常，assistant 气泡同步显示当前步骤
- [ ] 完成后：右栏结果展示、编辑保存、重新生成重置逻辑均正常；「存入产物库」出现 toast 且按钮变「已存入产物库」
- [ ] 入库产物 `params` 含 `mode` / `topic`（或 `sourceLength`）/ `duration` / `model` / `modelName` / `input`；送 TTS 后 handoff 预选正常
- [ ] 多次发送形成可滚动回看的历史；每次发送触发新一次生成并重置右栏（含 savedId/dirty）
- [ ] 全程无控制台报错、无网络请求；冥想页回归正常

## 7. 明确不做（Out of Scope）

- 不加显式模式切换控件（C1：自然语言自动识别）
- 不从自然语言解析时长（C3：控件为唯一来源）
- 不模拟不同模型间的生成差异（C5）
- 不做多轮追问微调（沿用冥想页单轮触发式决策）
- 结果区除「目标时长」chip 外不做任何改动（C4）
