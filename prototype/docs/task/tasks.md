## 2. 技术方案总览

### 2.1 架构：多页面应用（MPA）

- 每个功能模块一个独立 HTML 页面，通过侧边栏普通链接 `<a href>` 跳转
- 侧边栏由公共 `layout.js` 动态注入到每个页面，自动高亮当前页
- 页面间数据传递全部依赖 localStorage：
  - **产物库**：各模块输出自动入库，下游模块从库中下拉选择输入
  - **交接暂存（handoff）**：跨页跳转时写入 `{targetPage, selectedId}`，目标页加载后读取并自动预选，随后清除
- **音频产物以「配方」形式存储**（生成参数 + 脚本文本），播放时由 Web Audio 引擎实时重合成，不在 localStorage 中存音频数据（避免超限）

### 2.2 目录结构规划

### 2.3 产物数据模型（store.js）

```js
Artifact {
  id: String            // 唯一 ID（时间戳+随机）
  type: String          // 'script_meditation' | 'script_podcast' | 'voice' | 'bgm' | 'mix'
  name: String          // 展示名（自动生成或用户命名）
  createdAt: Number     // 生成时间戳
  params: Object        // 生成参数快照（主题/时长/引擎/音色/语速/风格/闪避模式等）
  content: {
    text?: String       // 脚本类产物的正文（含标记）
    segments?: Array    // 解析后的段落结构（供时间轴/音频引擎使用）
  }
}
```

localStorage key：`audio_studio_proto_v1`，结构 `{ artifacts: [], handoff: null }`，含版本号与解析兜底。

### 2.4 Web Audio 引擎要点（audio.js）

- **占位人声**：解析脚本标记 → 语音段（振荡器 + 幅度包络模拟说话节奏）+ 停顿段（真实静音）
  - `[情绪:x]` 映射音高/波形参数；`[语速:x]` 映射段时长；`[停顿 Ns]` 映射静音时长
- **占位音乐**：风格 → 和弦进行 + 波形 + 滤波参数；段落标签（Intro/Build Up/Drop/Outro）→ 能量包络结构
- **播放控制**：play / pause / stop / seek，播放进度回调
- **混音**：人声 GainNode + 背景 GainNode，音量比例与起始偏移实时可调
- **闪避（双模式）**：
  - 模式 A「静音段压低」（PRD 字面）：检测人声静音段（≥1s）→ 压低背景音
  - 模式 B「人声时压低」（常规闪避）：人声出现 → 压低背景音，静音时恢复
  - 可整体关闭
- **波形**：由合成参数推导采样数据，Canvas 绘制；合成页绘制双轨叠加波形
- 引擎**纯函数化重合成**：相同配方（params + text）生成确定相同的音频

## 3. 任务分解

### T1 项目脚手架与全局样式

**内容**
- 按目录规划创建全部文件骨架（7 个 HTML + CSS + JS 空模块）
- `main.css`：暗色主题（CSS 变量定义色板/间距/圆角）、通用组件样式（按钮、表单控件、下拉、滑块、卡片、标记徽章、进度条、波形容器、Tab、开关、弹层）
- `layout.js`：侧边栏注入（7 个导航项 + 图标）、当前页高亮、页面标题设置

**验收标准**
- 任一页面直接用浏览器打开，侧边栏正常渲染且当前项高亮
- 无控制台报错，无外部网络请求

---

### T2 数据层与 Mock 数据

**内容**
- `store.js`：Artifact 模型、增删查 API（`save / list(type) / get(id) / remove(id) / clear`）、localStorage 读写与版本兜底、handoff 读写清除
- `mock.js`：
  - 冥想脚本 ×3（不同主题/时长，含 `[停顿]` `[情绪]` `[吸气]` `[呼气]` `[语速]` 全套标记）
  - 播客脚本 ×2（话题生成版 + 文本润色改编版）
  - 音色库：阿里云 ×4、火山引擎 ×4（名称 + 风格描述 + 试听参数差异）
  - 音乐风格 ×6（古风禅意/电子疗愈/钢琴抒情等，各含和弦与音色参数）
  - 模拟生成函数：`mockGenerate(module, params) → Promise`（内部 1.5~2.5s 延迟，供进度动画）

**验收标准**
- 控制台调用 CRUD API 正常，刷新页面数据保留
- 手动注入脏数据（非法 JSON / 缺字段）不崩溃，走兜底逻辑

---

### T3 Web Audio 音频引擎

**内容**
- 按 2.4 要点实现 `audio.js` 全部能力
- 提供独立验证方式（临时在 TTS 页或 bgm 页挂最小 demo 面板：加载 Mock 脚本 → 播放 → 调语速 → 切情绪 → 播放音乐 → 切风格）

**验收标准**
- 语速 0.5x / 1.0x / 1.5x 播放时长差异明显（时长按比例变化）
- 不同情绪标签、不同音乐风格听感可辨
- 闪避两模式 + 关闭状态三档效果差异清晰可听
- 相同配方两次合成结果一致（确定性）

---

### T4 冥想剧本页（meditation-script.html）

**内容**
- 输入表单：主题关键词输入 + 预设主题快捷选择（深海放松/焦虑缓解/清晨唤醒等）、目标时长（5/15/30 分钟单选）
- 模拟生成：提交 → 进度动画 → 按主题+时长匹配 Mock 脚本
- 结果展示：
  - 标记徽章渲染（`[停顿 5s]` 等渲染为彩色徽章，非纯文本）
  - 时间轴条：语音段/停顿段分段着色，显示预估总时长
- 可编辑：切换编辑模式（textarea），编辑后按最新文本重新解析时间轴
- 动作：重新生成 / 存入产物库 / 送去 TTS（写 handoff + 跳转 tts.html）

**验收标准**
- 全流程走通；编辑后保存的是修改后文本且时间轴同步更新
- 跳转 TTS 页后脚本下拉自动选中该产物
- 输入校验：主题为空时禁用生成按钮

---

### T5 播客剧本页（podcast-script.html）

**内容**
- 输入双 Tab：方式 A 话题关键词 / 方式 B 粘贴文本（多行 textarea）
- 模拟生成：方式 A 按话题匹配 Mock 讲述脚本；方式 B 返回「润色改编后」版本（Mock 内置原文→改编对照）
- 结果展示 + 可编辑 + 动作（同 T4）

**验收标准**
- 两个 Tab 均可独立走通
- 粘贴文本模式结果为改编版而非原文（体现 AI 润色）
- Tab 切换不丢失已填内容

---

### T6 TTS 合成页（tts.html）

**内容**
- 输入源：产物库脚本下拉（冥想+播客，含名称/类型/时间）+ 粘贴兜底
- 场景类型选择（冥想引导/单人播客）：切换时联动参数预设（语速默认 0.8x/1.0x、推荐音色高亮、预设说明文案）
- 引擎选择（阿里云/火山）→ 联动音色下拉
- 音色选择 + 单独试听按钮（短句占位音）
- 语速滑块 0.5x ~ 1.5x、音调滑块（可选）
- 模拟合成 → 人声轨预览（波形 + 播放/暂停/进度，按脚本实时合成占位音）
- 动作：存入产物库（params 完整快照）/ 送去合成（handoff → mixdown.html）

**验收标准**
- 场景切换参数联动正确；引擎切换音色列表联动正确
- 语速滑块变化 → 波形长度与播放时长同步变化
- 产物入库后 params 可完整回溯（引擎/音色/语速/音调/来源脚本 id）

---

### T7 背景音生成页（bgm.html）

**内容**
- 风格：预设风格卡片选择 + 自由描述输入（组合可跨风格融合，如「笛子+电子氛围」）
- 目标时长滑块 1~10 分钟
- 段落结构标签可选勾选：Intro / Build Up / Drop / Outro
- 模拟生成 → 音轨预览（波形按段落结构分段展示能量差异 + 播放）
- 动作：存入产物库 / 送去合成

**验收标准**
- 不同风格听感与波形形态可辨差异
- 勾选/取消段落标签 → 波形分段结构可视化变化
- 产物 params 含风格描述、时长、段落标签

---

### T8 最终合成页（mixdown.html）

**内容**
- 人声轨选择（产物库 voice 下拉，可为空 = 纯背景音导出）
- 背景音轨选择（产物库 bgm 下拉，可选跳过）
- 调节面板：
  - 人声/背景相对音量比例滑块
  - 背景音起始位置偏移滑块
  - 闪避总开关 + 模式切换（模式 A 静音段压低 / 模式 B 人声时压低）+ 模式说明文案（标注两种语义差异，辅助产品决策）
- 模拟合成 → 成品预览：双轨叠加波形 + 播放（播放中实时体现音量比例、偏移、闪避效果；闪避作用区段在波形上高亮）
- 导出按钮（Mock：仅展示「MP3 320kbps / WAV 16bit 44.1kHz」格式选择与成功提示，不产出真实文件）
- 规则提示：背景音短于人声 → 显示「循环填充」提示；长于人声 → 显示「截断」提示；仅人声 → 直接透传提示

**验收标准**
- 双闪避模式播放效果差异明显，波形高亮区段与听感一致
- 音量比例、偏移调节播放中实时生效（无需重新合成）
- 三种轨道组合（人声+背景 / 仅人声 / 仅背景）均可走通并显示对应规则提示

### T9 产物库页 + 首页概览（library.html / index.html）

**内容**
- 产物库：
  - 类型分组或筛选 Tab（全部/脚本冥想/脚本播客/人声/背景音/成品）
  - 卡片：名称、类型徽章、参数摘要（引擎/音色/时长/风格等）、生成时间
  - 操作：查看详情（弹层展示完整参数与内容）、送下游（脚本→TTS、人声/背景→合成）、删除；顶部清空全部（需确认）
- 首页：工作台概览（模块卡片入口、产物计数、最近产物列表、快速开始引导文案）

**验收标准**
- 各类型产物卡片信息正确，操作均可用
- 「送下游」跳转后目标页正确预选
- 删除/清空后列表与各页下拉同步更新

### T10 整体联调与验收

**内容**
- 全链路走查：冥想脚本→TTS→合成→入库；播客脚本→TTS→合成；背景音→合成（纯音乐路径）；各模块独立使用

- 浏览器兼容自查：Chrome / Edge 最新版

**验收标准（整体清单）**
- [ ] 7 个页面导航正常、当前页高亮
- [ ] 冥想/播客脚本生成、编辑、入库、送 TTS 全通
- [ ] TTS 参数联动、预览播放、入库、送合成全通
- [ ] 背景音生成、预览、入库、送合成全通
- [ ] 合成页双闪避模式可切换且效果可辨，三种轨道组合可走通
- [ ] 产物库增删查、送下游、清空全通
- [ ] 刷新页面后产物与页面状态保留
- [ ] 全程无控制台报错、无网络请求

## 4. PRD 缺口在原型中的处理方式

| PRD 问题 | 原型处理 |
|----------|----------|
| 闪避逻辑疑似写反（3.5） | 双模式可切换 + 说明文案，原型演示辅助产品决策 |
| 架构图背景音误汇入 TTS（第 2 节） | 原型按正确流向实现：背景音轨直达最终合成，不经 TTS |
| 缺少剧本编辑环节 | 生成后可编辑（D4） |
| 模块间流转未定义 | 产物库 + handoff 机制（D3） |
| 「纯音乐」场景与背景音模块概念重叠 | 原型统一为背景音模块；纯音乐路径 = 该模块独立使用 + 合成页仅选背景轨 |
| 缺少重新生成 | 各生成模块均提供重新生成按钮 |

## 5. 任务依赖与建议顺序

T1 → T2 → T3（公共层先行）→ T4 / T5 / T7（三个生成模块可并行）→ T6 → T8 → T9 → T10
